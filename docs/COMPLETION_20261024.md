# ttp_flac 后续补全与验收

日期：2026-10-24。发行版本：`2026.10.24`。

## 修改

多声道使用标准掩码；20-bit 等非整字节精度以向上取整的容器位数输出并左对齐，独立记录有效精度。TTA 无可靠掩码时维持未知布局。

## 验证

20-bit／96 kHz／6 声道 288000 个样本值经独立 libFLAC 编码核对，24-bit 多声道与三系统 PCM 校验通过。

Windows 11、XP SP3 x86、Win7 SP1 的组合回归各 33 项通过，其中 19 组 PCM 样本数及校验相同。这是组合测试数量，不代表本插件单独具有 33 个独立用例。Win11 按用户要求代为现代 Windows 验证，无独立 Win10 实测。

## 保留边界

后续补充的[历史 TTA 浮点位模式和跨帧定位复核](TTA_FLOAT_BOUNDARIES_20261024.md)已完成本机 112 项检查，原 DLL 与重建 DLL 输出一致。测试是本地生成样本；历史真实 float32 存档和原生 32-bit 独立编码器样本仍未覆盖。官方整数范围与 FFmpeg 实际编码精度均不能作为原生 int32 已支持的证据。原版 Win11 的 5／7 声道接收另有宿主输出边界，详见工作区综合报告。

测试代码和样本只保存在工作区 `rebuild/tests/plugins_complete_20261024`，不进入 Action 或发行 ZIP。运行 ZIP 仅含 DLL 与 SHA256SUMS；许可证留在仓库及既有对应源码包。本轮没有升级上游依赖版本或增加外部解码 DLL。
